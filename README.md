# Wander Kyrgyzstan

Discover Kyrgyzstan: yurts, alpine treks, horse tours and lakes. Plan and book curated tours across the Tian Shan with an AI travel guide.

## Getting Started

Проект разделён на две части:

- `Frontend/` — фронтенд (Vite/React)
- `tour_backend/` — бекенд (Python/Django)

### Frontend

1. Install dependencies: `cd Frontend && npm install`
2. Run development server: `cd Frontend && npm run dev`
3. Build for production: `cd Frontend && npm run build`

### Backend

См. `tour_backend/requirements.txt` и `tour_backend/manage.py`.
